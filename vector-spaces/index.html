How to approach these

1. For "is it a subspace?": check $\mathbf 0$ first, then try $c = -1$ and $c = 2$, then add two members from different "pieces" of the condition.

2. Homogeneous linear conditions ($= 0$, no products, no inequalities) give subspaces; everything else is suspect.

3. Span, independence and membership all become one row reduction with the vectors as columns.

4. For invented operations, test $1v = v$ and $(a+b)v = av + bv$ first.
