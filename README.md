# Fall 2026 — public study apps

Installable study web apps (PWAs) built from standard textbook material only. Each folder is a self-contained
static site: open `index.html` through any local server (`python3 serve.py` inside the folder) or drop the
folder on a static host.

| App | Folder | What it covers |
|---|---|---|
| Binomial & Multinomial Lab | `binomial-multinomial/` | Binomial coefficients, Pascal's triangle, the binomial theorem and its standard derived identities (row and alternating sums, differentiate/integrate, Vandermonde, hockey stick), multinomial coefficients and the multinomial theorem. Reference sheets, three interactive explorers, and a practice quiz with 57 randomised generators. |
