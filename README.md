# Fall 2026 — public study apps

Installable study web apps (PWAs) built from standard textbook material only. Each folder is a self-contained
static site: open `index.html` through any local server (`python3 serve.py` inside the folder) or drop the
folder on a static host.

| App | Folder | What it covers |
|---|---|---|
| Binomial & Multinomial Lab | `binomial-multinomial/` | Binomial coefficients, Pascal's triangle, the binomial theorem and its standard derived identities (row and alternating sums, differentiate/integrate, Vandermonde, hockey stick), multinomial coefficients and the multinomial theorem. Reference sheets, three interactive explorers, and a practice quiz with 57 randomised generators. |
| Fields & Vector Spaces Lab | `vector-spaces/` | Field axioms and $\mathbb Z_p$, the vector-space axioms and their consequences, the standard spaces ($\mathbb R^n$, $\mathbb C^n$, polynomials, functions, matrices), the subspace test with worked examples and counterexamples, span, linear independence, bases and dimension. Reference sheets, a $\mathbb Z_n$ table / axiom checker, an interactive subspace checker on subsets of $\mathbb R^2$ and $\mathbb R^3$, a span & independence lab, and a practice quiz with 36 randomised generators. |
| Bijection Lab | `bijections/` | Injective, surjective and bijective functions: editable arrow diagrams on finite sets with preimage-count charts, windowed diagrams on infinite sets (ℕ, 2ℕ, ℤ, ℕ×ℕ with Cantor pairing), the horizontal-line test on real functions with domain/codomain restriction and inverse graphs, and the counting formulas for functions, injections, surjections and bijections. |
