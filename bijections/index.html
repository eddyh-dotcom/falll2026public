Why infinite sets behave differently. On a finite set, an injective map A → A is automatically surjective (pigeonhole). On ℕ that fails: n ↦ n + 1 is injective yet misses 0, and n ↦ 2n is a bijection from ℕ onto a proper subset of itself. Having a bijection with a proper subset is exactly what it means for a set to be infinite (Dedekind). Two sets have the same cardinality when some bijection connects them, which is why ℕ, the even numbers, ℤ and ℕ×ℕ are all “the same size”: countably infinite.

How many functions A → B are there, and how many of each kind?

KindFormulaValue

Function f : A → B
Every a ∈ A is sent to exactly one f(a) ∈ B. (Every element of A has exactly one arrow leaving it.)
Injective (one-to-one)
f(a₁) = f(a₂) ⇒ a₁ = a₂. No two arrows land on the same element of B. For real functions: every horizontal line meets the graph at most once.
Surjective (onto)
For every b ∈ B there is some a ∈ A with f(a) = b. Every element of B is hit. For real functions: every horizontal line through the codomain meets the graph at least once.
Bijective
Injective and surjective: a perfect pairing of A with B. Then f⁻¹ : B → A exists and is also a bijection. On finite sets a bijection A → B forces |A| = |B|; that is the whole point of a bijective proof: to show two sets have the same size, exhibit a bijection between them.
Pigeonhole consequences
If |A| > |B| no function A → B is injective; if |A| < |B| none is surjective. If |A| = |B| is finite, injective ⇔ surjective ⇔ bijective.
Preimage (fiber) of b
f⁻¹({b}) = { a ∈ A : f(a) = b }. Injective ⇔ every fiber has at most one element; surjective ⇔ every fiber is non-empty; bijective ⇔ every fiber has exactly one element.
Same cardinality
|A| = |B| means a bijection A → B exists. A set is countably infinite if it is in bijection with ℕ; a set is infinite (Dedekind) if it is in bijection with a proper subset of itself, e.g. ℕ → 2ℕ, n ↦ 2n. For infinite sets an injective self-map need not be surjective.
